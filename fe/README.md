# מערכת לניהול פניות – Frontend

צד הלקוח של מערכת ניהול הפניות: אפליקציית Angular 22 עם Angular Material, שעובדת מול ה־REST API של ה־Backend.

> התכנון, ההחלטות וה־Issues נמצאים ב־[requests-management-docs](https://github.com/naomy55978/requests-management-docs) – נקודת הכניסה לפרויקט. ה־Backend נמצא ב־[requests-management-be](https://github.com/naomy55978/requests-management-be).

## מצב נוכחי

האפליקציה תיווצר בשורש ה־Repo הזה ב־M7, לפי תוכנית העבודה ([Issue #32](https://github.com/naomy55978/requests-management-docs/issues/32)).
המסכים המתוכננים: רשימת פניות עם סינון, חיפוש, מיון ודפדוף בצד השרת; כרטיסי סיכום; עדכון סטטוס עם טיפול ב־409; עדכון מרובה; היסטוריית שינויים; התחברות.

הוראות התקנה והרצה יתווספו ב־M7–M9.
