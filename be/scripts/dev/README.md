# סקריפט אימות אופציונלי

**`verify-read-api.js`** משווה את תשובות ה־API לשאילתות SQL ישירות על **מסד הפיתוח המלא – 100,000 פניות** (עם כותרות בעברית ושמות ארגונים בעברית ובאנגלית):
- `totalCount` של סינונים משולבים וחיפוש מול `COUNT(*)` ישיר;
- סדר המיון בכל שדה מול `ORDER BY` (כולל 500 כותרות עבריות ברצף), דפדוף יציב ודף 1000;
- ה־summary מול `GROUP BY` על כל הטבלה;
- פורמט שגיאות 400/401/404/405, תיעוד OpenAPI, וזמני תגובה חמים.

את זה הבדיקות האוטומטיות אינן מכסות: הן רצות על 40 פניות קבועות בטקסט ASCII (D‑21), כדי להיות מהירות ויציבות בכל Push.

**הסקריפט אופציונלי.** לא צריך אותו כדי לבנות, להריץ או לבדוק את הפרויקט, וה־CI לא מריץ אותו. ההתנהגות הנדרשת (סינון, Validation, עדכון, Conflict, Audit, Bulk, Cache, Concurrency) מוכחת בבדיקות האוטומטיות (`dotnet test`).

**הפעלה** – מתיקיית השורש של ה־Repo, כש־API רץ על המסד הזרוע:

```
node scripts/dev/verify-read-api.js
```

דרישות: Node.js 18 ומעלה ו־`sqlcmd` ב־PATH. משתני סביבה אופציונליים: `API_URL` (ברירת מחדל `http://localhost:5084`), ‏`SQL_SERVER` (ברירת מחדל `(localdb)\MSSQLLocalDB`). הסקריפט **לא משנה נתונים**, ומסתיים ב־`ALL CHECKS PASSED` (קוד יציאה 0) או ברשימת הבדיקות שנכשלו.

כלי מדידת השאילתות `scripts/MeasureQueries.cs` נמצא בתיקייה `scripts/`: הוא מקור התוצאות שב־`docs/PERFORMANCE.md`.
