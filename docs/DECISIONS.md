# החלטות טכנולוגיות

מסמך זה מרכז את ההחלטות המשמעותיות בפרויקט: מה הוחלט, למה, ואילו חלופות נשקלו.
ההחלטות יעודכנו לאורך המימוש (Issue #46), כולל מגבלה ידועה ודבר שניתן לשפר.
